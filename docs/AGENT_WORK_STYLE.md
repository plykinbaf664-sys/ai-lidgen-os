# Agent Work Style

Inspect the actual execution path before diagnosing from old reports. Prefer tracing one real failure from input through provider results, evidence extraction, person scoring, contact verification and Ready decision. Change the smallest responsible boundary; redesign the research loop only if traces demonstrate a systemic issue.

Treat search examples as semantics, not a closed keyword dictionary. Preserve useful evidence between research rounds. Evaluate useful evidence per action and meaningful improvement in confirmed contacts, not just SERP counts or fallback Ready.

Avoid false certainty. Do not invent people, domains, buying intent, personal-email ownership or test results. Do not equate MX acceptance with personal mailbox verification. Avoid unnecessary broad refactors of stable UI, storage and lifecycle.

Keep provider failures explicit; use budgets and compact evidence, never raw dumps or chain-of-thought. Protect uncommitted user changes, do not expose keys, and do not send live emails, push or deploy without permission.

For substantial changes, write/update a living ExecPlan. Verify with targeted checks, a bounded real research run and appropriate transaction regressions. Finish with measured results and outstanding limitations.
